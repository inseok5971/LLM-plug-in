====================================================================
⚡ AI 플러그인 스위치보드 (Plugin Switchboard) 사용 설명서
====================================================================

안녕하세요! 이 프로그램은 Claude(클로드), Cursor, Antigravity 등에서
플러그인(도구)이 너무 많아 발생하던 "토큰 낭비"와 "도구 충돌(원치 않는 플러그인 무차별 호출)"을
해결해 주는 [한국어 전용 플러그인 관리 스위처]입니다.

--------------------------------------------------------------------
1. 실행 방법 (대시보드 열기)
--------------------------------------------------------------------
- [맥(Mac) 사용자]: '맥용_실행하기.command' 파일을 더블 클릭하세요.
- [윈도우 사용자]: '윈도우용_실행하기.bat' 파일을 더블 클릭하세요.

브라우저가 자동으로 열리며 직관적인 스위치보드 화면(http://localhost:8765)이 뜹니다.
여기서 원하는 플러그인만 스위치를 켜고 끌 수 있습니다.

--------------------------------------------------------------------
2. Claude 데스크톱(Claude Desktop)과 연동하는 법 (30초 완료)
--------------------------------------------------------------------
1) Claude Desktop 앱을 켭니다.
2) 좌측 상단 [Claude] 메뉴 -> [Settings (설정)] -> [Developer (개발자)] 탭 클릭
3) [Edit Config] 버튼을 누르면 설정 파일(claude_desktop_config.json)이 열립니다.
4) 내용 안에 아래 코드를 복사해서 붙여넣고 저장하세요:

{
  "mcpServers": {
    "plugin-switchboard": {
      "command": "python3",
      "args": [
        "이_폴더의_전체경로/server.py",
        "--mcp"
      ]
    }
  }
}

※ "이_폴더의_전체경로" 부분에 현재 압축을 푼 폴더 경로를 넣어주세요.
   (예: /Users/사용자이름/Desktop/AI_스위치보드/server.py)

5) Claude Desktop 앱을 완전히 껐다가 다시 켜면 끝!

--------------------------------------------------------------------
3. 무엇이 좋아지나요?
--------------------------------------------------------------------
1) [💬 순수 질문·대화 (전체 끄기)]:
   - 평소에 그냥 일반 번역이나 가벼운 질문을 할 때, 무거운 영상/이미지 도구가 호출되는 것을 100% 방지합니다.

2) [🎬 영상 모드]:
   - Runway, Luma 등 영상 플러그인이 여러 개 깔려 있어도, 내가 켜둔 단 하나의 모델만 사용하게 하여 충돌을 막습니다.

3) 실시간 토글:
   - 웹 화면에서 스위치를 내리는 순간, AI는 해당 도구를 아예 시야에서 지워버려 완벽하게 제어됩니다.

문의 및 피드백 환영합니다!
