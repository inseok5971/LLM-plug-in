## 🚀 [필독] 10초 초간단 설치 방법 (윈도우 & 맥 동일)

컴퓨터를 잘 몰라도 10초 만에 바로 설치할 수 있습니다!

### 1단계: 파일 다운로드
1. 이 깃허브 화면 우측 상단에 있는 초록색 **`Code`** 버튼을 클릭합니다.
2. 맨 아래 **[Download ZIP]**을 눌러 파일을 다운로드하고 **압축을 풉니다.**

---

### 2단계: 브라우저에 등록하기 (크롬 / 엣지 / 웨일)
1. 평소 쓰시는 웹 브라우저의 새 탭 주소창에 아래 주소를 복사해 입력하고 Enter를 칩니다:
   - **크롬(Chrome)**: `chrome://extensions`
   - **엣지(Edge)**: `edge://extensions`
   - **네이버 웨일(Whale)**: `whale://extensions`
2. 화면 오른쪽 위에 있는 **[개발자 모드]** 스위치를 켭니다 (파란색으로 ON).
3. 화면 왼쪽 위에 나타나는 **[압축해제된 확장 프로그램을 로드합니다]** 버튼을 클릭합니다.
4. 방금 1단계에서 압축을 풀었던 **`LLM-plug-in` 폴더를 선택**합니다.
5. **설치 완료! 🎉**

---

### 3단계: 화면에서 확인하기
1. **[claude.ai](https://claude.ai)** 나 **[chatgpt.com](https://chatgpt.com)** 에 접속합니다.
2. 화면 오른쪽 아래에 떠 있는 **`⚡ 스위치보드`** 버튼을 누르면 화면 안에서 사이드바가 바로 열립니다!

---

## 🧐 왜 만들었나요?

AI(LLM)에 영상, 이미지, 검색 등 여러 플러그인과 도구를 잔뜩 설치해두면 다음과 같은 문제가 생깁니다:

1. **도구 중복 호출 & 충돌**: 영상 제작을 시켰더니 깔려 있는 여러 영상 모델 플러그인이 한꺼번에 실행되거나 엉뚱한 도구가 호출됨.
2. **토큰 낭비 & 답변 지연**: 평소에 가벼운 일상 질문이나 번역만 물어봤는데도 무거운 플러그인들이 백그라운드에서 감지되어 토큰이 낭비되고 응답이 느려짐.
3. **어려운 기술 용어**: 영어가 익숙하지 않은 사용자에게 복잡한 시스템 명칭은 직관적이지 않음.

👉 **"내가 대화하는 Claude / ChatGPT 화면 안에서 바로! 8대 목적별 카테고리 스위치로 필요한 플러그인만 콕 집어 켜고 끌 수 있게 만들었습니다."**

## ✨ 핵심 기능

- **📱 100% 인앱 완벽 통합**: 별도의 인터넷 창이나 프로그램을 띄울 필요 없이, Claude/ChatGPT 대화창 바로 옆에서 조작.
- **💬 원클릭 "순수 대화 모드 (전체 끄기)"**: 가벼운 일반 질문 시 버튼 한 번으로 모든 플러그인을 OFF하여 안전하게 대화.
- **📂 8대 목적별 아코디언 카드**: 복잡하게 나열되지 않고 카테고리별로 깔끔하게 접고 펼쳐지는 직관적인 묶음.
- **🎛️ 자유로운 다중 스위칭**: 1개만 켜도 되고 2~3개를 동시에 켜서 결과물을 비교할 수도 있음.
- **🇰🇷 100% 한국인 친화 설명**: 기술 용어 대신 *"영화 수준 초고화질"*, *"인물 동작 자연스러움"* 등 알기 쉬운 한 줄 안내.

| 카테고리 | 대표 플러그인 | 하는 일 |
|---|---|---|
| **🎬 영상 만들기 및 편집** | Runway Gen-3, Luma, Kling, Pika 2.0 | 글이나 사진으로 초고화질 비디오 제작 및 특수효과 |
| **🎨 그림 및 디자인 그리기** | Midjourney, FLUX.1, DALL-E 3 | 일러스트, 캐릭터, 로고, 글자 포함 이미지 생성 |
| **🎵 목소리 및 음악** | ElevenLabs, Suno, Whisper | AI 성우 목소리 더빙, 노래 작곡, 음성 회의록 받아쓰기 |
| **🔍 인터넷 검색 및 최신 정보** | Google Search, Perplexity | 실시간 국내외 뉴스, 주가 시세, 출처 기반 요약 검색 |
| **📄 문서·업무·이메일** | 스마트 PDF 분석기, Notion, 구글 캘린더 | 긴 계약서/보고서 핵심 요약, 메모 저장, 일정 등록 |
| **💻 내 컴퓨터 파일 & 시스템 제어** | 파일 탐색기, 터미널 실행기 | 컴퓨터 폴더 내 파일 읽기/쓰기, 설정 명령어 대신 실행 |
| **🌐 웹 브라우저 자동 조작** | 브라우저 자동 조작기 (Puppeteer) | AI가 직접 웹페이지를 클릭하고 캡처하며 정보 수집 |
| **📊 통계 & 데이터 분석** | 데이터 차트 시각화 도구 | 엑셀 표 데이터를 분석하고 예쁜 그래프 차트로 변환 |

## 🛠️ 기술 스택
- **Extension Standard**: Chrome Extension Manifest V3 (Cross-Browser 호환)
- **Front-end**: Pure Native JavaScript & CSS (외부 라이브러리 의존성 없이 초고속 로딩)
- **Storage**: `chrome.storage.local` (브라우저 간 스위치 상태 실시간 동기화)
