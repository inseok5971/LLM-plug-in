## 💡 본 프로젝트의 핵심: "윈도우 & 맥 올인원(All-in-One) 패키지"

별도로 윈도우용과 맥용 다운로드 링크를 찾아다니실 필요가 없습니다!  
**이 저장소 하나만 다운로드받으면, 본인의 운영체제(맥 또는 윈도우)에 맞는 실행·설치 파일이 세트로 완벽하게 준비**되어 있습니다.

```text
📁 LLM-plug-in (다운로드 받은 폴더)
 ├── 🍎 맥(macOS) 전용 파일
 │    ├── start_mac.command             # 맥용 더블클릭 실행기
 │    ├── create_shortcut_mac.command   # 맥 바탕화면에 앱 아이콘 자동 생성
 │    └── stop_mac.command              # 맥용 더블클릭 종료기
 │
 ├── 🪟 윈도우(Windows) 전용 파일
 │    ├── start_windows.bat             # 윈도우용 더블클릭 실행기 (Pure ASCII 100% 호환)
 │    ├── create_shortcut_windows.bat   # 윈도우 바탕화면에 바로가기 아이콘 자동 생성
 │    └── stop_windows.bat              # 윈도우용 더블클릭 종료기
 │
 ├── ⚙️ 핵심 엔진 & 설정
 │    ├── main.py                       # 경량 HTTP 및 표준 MCP 게이트웨이 서버
 │    ├── widget.html                   # 스마트폰 크기의 독립 미니 위젯 UI (v2.2)
 │    └── config.json                   # 8대 카테고리 19종 플러그인 상태 DB
```

## 🆕 v2.2 주요 업데이트 내역 (What's New in v2.2)

- 🎛️ **각 AI 앱별(Claude / Cursor / Antigravity) 개별 독립 제어 탭 탑재**:
  - 한 번에 모든 AI가 바뀌는 것이 아니라, 상단에서 `[🟠 Claude]`, `[🔵 Cursor]`, `[🟣 Antigravity]`, `[🌐 전체 공통]` 탭을 선택하여 **각 AI 앱마다 원하는 플러그인을 독립적으로 켜고 끌 수 있습니다**.
  - 각 탭마다 현재 켜져 있는 플러그인 개수(`Claude 12`, `Cursor 10`, `Antigravity 14`)가 실시간 배지로 표시됩니다.
- 📋 **투명한 "플러그인 가져오기" 상세 감지 보고서 모달**:
  - `[가져오기]` 버튼을 누르면 어떤 파일에서 감지했는지(`Claude Desktop`, `Cursor`, `Antigravity`), 새로 발견된 플러그인과 이미 등록된 플러그인이 무엇인지 팝업 창으로 투명하고 상세하게 안내합니다.
- ⚡ **실시간 1:1 동기화 정밀화 (`● 실시간 동기화`)**:
  - 각 AI가 도구 상태를 조회할 때 해당 앱 전용 활성화 목록만 정확하게 전달하도록 동기화 엔진을 전면 강화했습니다. (위젯의 숫자와 AI가 인식하는 도구 개수가 100% 일치)
- 🖥️ **스마트폰 크기의 독립 데스크톱 미니 위젯 창**:
  - 주소창이나 브라우저 탭 없는 순수 앱 창(420x740)으로 Claude나 Cursor 창 옆에 깔끔하게 띄워놓고 조작할 수 있습니다.
- 📜 **상시 스크롤바 & 원클릭 접기/펼치기**:
  - 플러그인이 많아져도 상시 스크롤바로 언제든 부드럽게 탐색하며, 상단 `[▼ 전체 접기 / ▶ 전체 펼치기]` 버튼으로 깔끔하게 정리 가능합니다.

## 🧐 왜 만들었나요?

AI 파워 유저들은 웹 브라우저가 아니라 **Claude Desktop, Antigravity, Cursor** 같은 데스크톱 전용 앱을 주로 사용합니다.  
하지만 여러 플러그인을 깔아두면 다음과 같은 심각한 문제가 발생합니다:
1. **도구 중복 호출 & 충돌**: 영상 하나 만드는데 여러 영상 모델이 한꺼번에 발동되거나 엉뚱한 도구가 실행됨.
2. **토큰 낭비 & 버그**: 가벼운 일상 질문이나 번역만 물어봤는데도 무거운 플러그인이 실행되어 비용과 시간이 낭비됨.
3. **각 AI마다 다른 설정 필요**: 코딩용 Cursor에는 개발 도구만 켜고, Claude에는 문서·검색 도구만 켜고 싶은데 일괄 적용되는 불편함.

👉 **"내 모니터 구석에 작은 미니 리모컨 위젯을 띄워두고, 클릭 한 번으로 각 AI 앱의 플러그인을 실시간으로 개별 제어할 수 있게 만들었습니다!"**

## ⚠️ 필수 요구 사항 (사전 준비)
- **Python 3.8 이상**이 컴퓨터에 필요합니다:
  - **맥(Mac)**: 맥에는 Python이 기본적으로 준비되어 있어 바로 실행됩니다.
  - **윈도우(Windows)**: 컴퓨터에 Python이 깔려 있어야 실행됩니다.
    - *파이썬이 없다면?* 윈도우 시작 메뉴의 **Microsoft Store**에서 **"Python 3.12"**를 검색 후 [설치]를 누르시면 30초 만에 자동 설치됩니다!
    - 또는 공식 사이트([python.org](https://www.python.org/downloads/))에서 설치 시 맨 아래 **[Add python.exe to PATH]** 체크박스를 꼭 켜주세요.

## 🚀 운영체제별 사용 가이드 (10초 마스터)

우측 상단 초록색 **[Code]** 버튼 -> **[Download ZIP]**을 눌러 다운로드 후 압축을 풉니다.

### 🍎 맥(macOS) 사용자
1. **실행하기**: `start_mac.command` 더블 클릭!
2. **바탕화면에 앱 만들기 (추천)**: `바탕화면_바로가기_생성_맥.command`를 더블 클릭하면, 맥 바탕화면에 카카오톡 같은 **진짜 앱 아이콘(`AI 플러그인 스위치보드`)**이 생성됩니다. 앞으로는 그것만 누르면 켜집니다!
3. **종료하기**: `stop_mac.command` 더블 클릭!

### 🪟 윈도우(Windows) 사용자
1. **실행하기**: `start_windows.bat` 더블 클릭!
2. **바탕화면에 바로가기 만들기 (추천)**: `create_shortcut_windows.bat`을 더블 클릭하면, 윈도우 바탕화면에 바로가기 아이콘이 자동 생성됩니다!
3. **종료하기**: `stop_windows.bat` 더블 클릭!

## 🔗 AI 앱(Claude / Cursor 등) 자동 연동 방법

1. 위젯 창 맨 아래의 **`[앱 자동 연동]`** 버튼을 한 번만 클릭합니다.
2. 내 컴퓨터의 Claude Desktop, Cursor 설정 파일에 스위치보드가 **자동으로 즉시 등록**됩니다. 🎉
3. *(최초 연동 시 Claude Desktop 등 해당 앱을 한 번 완전히 종료(`Cmd+Q` 또는 `Alt+F4`) 후 재실행해 주시면 즉시 활성화됩니다.)*
4. 나중에 새 플러그인을 깔았을 때는 상단 **`[🔄 가져오기]`** 버튼을 누르면 새 플러그인만 감지되어 자동으로 추가됩니다!

## 💡 어떻게 모든 AI(Claude, 안티그래비티, Cursor 등)에 다 먹히나요?

전 세계 AI 앱들이 도구를 연결하는 글로벌 표준 규격인 **MCP(Model Context Protocol)**를 기반으로 작동합니다:

1. 사용자가 위젯에서 **원하는 AI 탭(예: Claude)을 누르고 런웨이(Runway)만 [ON]**으로 켭니다.
2. Claude Desktop 등 해당 AI 앱에 질문을 던지면,
3. 스위치보드가 **꺼져 있는 도구는 아예 숨겨버리고 켜진 도구만 AI에게 실시간 전달**합니다.
4. 따라서 AI가 불필요한 도구를 멋대로 부르지 않고, 스위치 상태에 맞춰 완벽하게 제어됩니다!

## 🛠️ 수동 연동 가이드 (직접 설정 파일을 열고 싶을 때)

만약 수동으로 설정하고 싶다면, 각 AI 앱의 설정 파일(`claude_desktop_config.json` 등)의 `mcpServers`에 아래 내용을 넣어주시면 됩니다:

```json
{
  "mcpServers": {
    "plugin-switchboard": {
      "command": "python3",
      "args": [
        "이_폴더의_전체경로/main.py",
        "--mcp",
        "--app=claude"
      ]
    }
  }
}
```
