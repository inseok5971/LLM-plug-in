# ⚡ AI 플러그인 스위치보드 (LLM Switchboard)
> **Claude, ChatGPT, Gemini 화면 안에서 직접 켜고 끄는 한국어 전용 플러그인 제어기**  
> 윈도우(Windows) 및 맥(macOS) 100% 공용 지원 (크롬 / 엣지 / 웨일 브라우저)

---

## 🎯 왜 만들었나요?
AI에게 작업을 시킬 때, 여러 플러그인이 한꺼번에 설치되어 있으면 **"필요 없는 영상/이미지 플러그인까지 무차별 호출"**되거나 **"토큰 낭비와 엉뚱한 오작동"**이 일어납니다.

이제 **대화하고 있는 그 화면 안에서 바로!** 8대 목적별 카테고리 스위치를 딸깍 켜고 꺼서, 원하는 도구만 똑똑하게 쓰세요.

---

## 🚀 10초 설치 방법 (윈도우 & 맥 동일)

1. 이 저장소 우측 상단 초록색 **[Code]** 버튼 -> **[Download ZIP]**을 눌러 다운로드 후 압축을 풉니다.
2. 사용하는 브라우저(크롬, 엣지, 웨일 등) 주소창에 아래 주소를 입력합니다:
   - 크롬(Chrome): `chrome://extensions`
   - 엣지(Edge): `edge://extensions`
   - 웨일(Whale): `whale://extensions`
3. 우측 상단 **[개발자 모드 (Developer mode)]** 스위치를 켭니다.
4. 좌측 상단 **[압축해제된 확장 프로그램을 로드합니다]** 버튼을 클릭합니다.
5. 방금 압축을 푼 폴더를 선택하면 설치 끝! 🎉

---

## 💡 사용하는 법

1. **[claude.ai](https://claude.ai)** 나 **[chatgpt.com](https://chatgpt.com)** 에 접속합니다.
2. 화면 오른쪽 아래에 **`⚡ 스위치보드` 플로팅 버튼**이 나타납니다.
3. 버튼을 누르면 우측에서 사이드바가 열리며, 원하는 플러그인을 즉시 켜고 끌 수 있습니다!
4. 브라우저 우측 상단 퍼즐 조각(확장 프로그램) 아이콘을 눌러 팝업 창으로도 바로 조작할 수 있습니다.

## 📂 8대 표준 카테고리 구성
- 🎬 **영상 만들기 및 편집**: 런웨이(Runway), 루마(Luma), 클링(Kling), 피카(Pika)
- 🎨 **그림 및 디자인 그리기**: 미드저니(Midjourney), 플럭스(FLUX), 달리 3(DALL-E 3)
- 🎵 **목소리 및 음악**: 일레븐랩스(ElevenLabs 성우), 수노(Suno 작곡), 위스퍼(Whisper 받아쓰기)
- 🔍 **인터넷 검색 및 최신 정보**: 구글 실시간 웹 검색, 퍼플렉시티(Perplexity)
- 📄 **문서·업무·이메일**: 스마트 PDF 분석기, 노션(Notion 연동), 구글 캘린더
- 💻 **내 컴퓨터 파일 & 시스템 제어**: 컴퓨터 폴더 파일 탐색기, 터미널 명령어 실행기
- 🌐 **웹 브라우저 자동 조작**: 웹 브라우저 자동 클릭 및 데이터 수집
- 📊 **통계 & 데이터 분석**: 데이터 차트 시각화
